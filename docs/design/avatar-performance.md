# 虚拟形象与语义表演

本文面向模型接入与表演实现，说明输入映射、表情、嘴型、语义配置及最终参数的控制仲裁。

avatar 拥有模型能力、嘴型、动作和参数仲裁。performance 拥有关键词映射与动作计划，通过 AvatarControl 提交语义意图。全部写入共享 avatar 的控制入口。

## 模型与输入映射

model_id 是运行配置内唯一的内部模型身份，绑定 VTS connection_id 和原生 provider_model_id。相同原生模型接入不同连接时使用不同 model_id，离线表情、嘴型和语义配置按内部身份保存。同一模型重新加载保留 model_id，模型代际随连接实例及模型加载更新，并绑定该代际的追踪输入、Live2D 输出、表达式参数及热键目录。重载、切换和目录失效后重新发现，旧连接或模型代际请求返回具体冲突。

同一 target_id 的连接别名共用当前模型加载代际与参数仲裁器，参数占用按实际目标、模型代际和最终输出参数身份归并。不同连接的配置通过各自内部 model_id 选择，控制写入使用共享目标协调域。

追踪输入与输出参数分别建模，例如 VoiceVolumePlusMouthOpen → ParamMouthOpen。冲突沿实际映射归并到最终输出参数；多个输入映射到一个输出时共享占用。值范围、映射转换和可混合方式来自当前模型元数据。

发现不足时允许显式输入绑定，并报告解析结果。读取本地模型目录是可选发现方式，不默认修改模型文件。不能解析的作用范围作为该动作的未知范围处理。

## 表情、热键与嘴型

表情配置包含互斥组、叠加关系和嘴部覆盖策略。同一模型代际内的互斥组切换串行执行，从读取状态、计算组内差异到执行及回读均处于同一协调边界，组外表情保留。部分执行失败时回读真实激活状态，保存已发生的变化并沿原操作处理恢复，操作结果表达实际效果及剩余恢复项，部分失败不得返回完整成功。热键按模型范围内的逻辑绑定解析当前 ID，重名返回歧义。

嘴型驱动消费实际 PCM 包络，申请 avatar 的嘴部参数租约。默认情况下，嘴型驱动向表情已锁定的嘴部参数让出控制权；模型配置可以明确允许指定输入覆盖。静音、结束、中断、取消和断线均释放该次播放的控制。

## 参数控制权

| 来源 | 默认优先关系与占用 |
| --- | --- |
| 明确手动参数控制 | 高于明确动作与表情 |
| 明确动作与表情 | 高于自动嘴型及语义，保留配置允许的嘴部覆盖通道 |
| 嘴型 | 高于语义，只申请模型及当前表情允许的嘴部通道 |
| 语义细节 | 使用整组可获得的输出，同级按规则优先级及稳定身份排序 |

先按模型映射和表情覆盖策略确定受保护的最终输出集合。明确允许嘴型覆盖的输入不受该表情对应嘴部锁定的阻拦，其余输出继续受保护；这项授权只适用于配置指定的通道。

### 同级竞争与整组授予

一次参数批次、一个语义命中或一个动作的完整输出集合构成一个意图。租约按整个集合授予。任意一个输出不可获得时，明确控制返回 PARAMETER_BUSY，自动意图整组跳过，其余互不重叠的独立意图可以继续。参数占用不建立候补队列，瞬时语义意图不会在占用解除后补播。

相同优先层的明确控制由先取得有效租约者保持控制权，后到的新请求在受理和外部写入前返回 PARAMETER_BUSY。幂等查询先于占用检查，原请求重试返回原操作。同一互斥表情组的切换继续由组协调器串行执行，按最新观察计算组内差异；这是组所有者的状态转换，每次转换更新授予身份。它不作为独立参数请求等待旧表情自动到期。

嘴型与嘴型竞争同一输出时，先取得有效租约的播放保持控制，后到包络整组跳过；下一份仍有效的新包络可以重新申请。语义候选先比较 priority 降序，省略值按 50 归一化，再按 mapping_id、model_id 和稳定 intent_id 的 Unicode 码点升序比较。performance 在一次调度步中收集同目标、同模型代际下已到期且仍有效的候选，形成固定批次后提交 AvatarControl。协调器按上述顺序逐个尝试整组授予，同一批次的候选排列顺序不改变结果；例如 A 请求 {X}、B 请求 {X,Y}、C 请求 {Y} 且优先级依次下降时，批次结果为 A 与 C。intent_id 由 performance 依据播放及命中身份生成。

跨调度批次以当时的有效占用为前置条件，排序更前的新候选可以接替当前较低排序的语义意图。某批次已跳过的命中保留其决定，后续释放不重新提交该命中；跨批次历史可以产生不同于一次合并批次的结果。迟到回调先检查播放、修订及片段有效期，通过后只参与下一批次。

单次意图中的两个不同输入解析到重叠最终输出时，在任何写入前返回 PARAMETER_CONFLICT；模型本身可以有合法的多对一映射，两个独立意图仍按同一输出仲裁。原生混合能力按模型元数据中的明确混合通道建模为一个输入，调用方不能通过重复输出隐式要求混合。未加载模型的配置在激活时完成这项校验，保存及活动修订继续分别表达。

### 抢占、释放与实际写入

租约包含唯一 lease_id、所有者、实际目标、模型代际、完整输出集合、输入通道、到期和释放方式。每次授予或替换产生新的 lease_id；写入、续期、撤销和释放都同时核对所有者、模型代际及当前 lease_id。同一所有者重新获授后，旧释放及旧帧也不能作用于新租约。

高优先意图可以撤销可安全停止的低优先控制。协调器先检查整组输出及所有受影响租约，再预留切换，停止旧写入、确认释放并一次性提交新整组所有权。任意旧意图失去一个输出时，其完整租约同时撤销，例如旧意图控制 {A,C}、新意图请求 {A,B} 时，旧意图不能继续写 C。切换预留期间其他请求不能取得这些输出，外部等待不占数据库写事务。

原生动作或表情无法安全停止时，新明确控制返回 PARAMETER_BUSY，自动意图整组跳过；自动仲裁不会擅自关闭该表情。显式表情组切换继续沿已配置切换流程处理。抢占过程中停止失败或结果未知时，不授予新租约，沿原操作核对已发生效果，协调器保留受影响输出的恢复占用。

租约的整组授予保证本地控制权一致。目标支持批量写入时使用一次批次，传输部分失败时回读真实值，停止受影响输出的后续自动写入并沿原操作恢复。执行结果分别表达获授、占用跳过、输入冲突、已发生效果及恢复项，部分外部效果不能作为整组成功返回。冲突明细通过有界原因及必要的详情资源提供。

释放后读取当前控制基线，只恢复仍有效的当前嘴型帧及未来语义意图。未被新意图接管的输出也按当前基线处理，旧快照不能覆盖后来的明确动作。被抢占的明确动作不自动重放，已过期语义命中不重新触发。租约到期只撤销本地授权，原生动作仍在生效或停止结果未知时继续保留观察占用，直到回读确认可以释放。

未知作用范围的动作执行期间同时暂停相关嘴型和语义自动写入，并记录暂停原因。动作结束或状态重新同步后读取当前控制基线，再恢复仍有效的自动控制，暂停期间的过时回调不补写。外部动作从事件被观察到时进入占用表，事件失步或连接重建时停止相关自动写入并重新发现状态。

## 独立语义配置

映射通过 semantic_mappings_save 保存，读取和查询通过独立工具完成。[映射 Schema](../../contracts/schemas/semantic-mapping.schema.json)包括标签、关键词、排除词、匹配方式、规则优先级、输入参数及过渡时间。

关键词在分句内按子串匹配，排除词优先。literal 使用原文字面，literal_casefold 对正文、关键词和排除词统一使用 Unicode casefold。分句和投影保留到合成正文的码点索引，折叠造成的长度变化映射回原字符区间。每次命中按 model_id、播放身份、正文修订、原字符区间和 mapping_id 生成稳定意图身份。多个语义规则竞争同一输出时，按[同级竞争与整组授予](#同级竞争与整组授予)确定胜出意图，所有输出按整组执行或跳过。规则优先级只作用于语义规则内部。

模型级 enabled、recognition_instructions、保存与活动修订通过 settings_get 的 performance 分区读取，条目通过分页列表及详情工具读取。recognition_instructions 用于调用方维护映射。普通 TTS 只传语音内容，既不要求逐次传标签，也不触发额外模型服务。

## 播放位置与调度

动作计划分别保存 playback_clock 和 alignment_source。playback_clock 取值为 pcm、provider_timestamp 或 native_lifecycle，表示实际播放位置的来源。alignment_source 取值为 provider_timestamp 或 text_estimate，表示合成正文区间与音频区间的关联来源。提供方对齐记录保留合成正文码点区间及对应音频区间，通过[PlaybackAlignment 端口](../architecture/interfaces.md#事件身份与时间)按播放及正文身份取得。没有正文时间戳时，按配置语速及分句估算片段区间，即使使用 pcm 播放时钟，对齐来源仍为 text_estimate。

pcm 时钟使用实际采样位置，provider_timestamp 时钟使用提供方实际播放进度。native_lifecycle 路径使用播放器发布的 started_monotonic_ms 与 clock_epoch 建立估算位置，延迟消费沿用同一起点。clock_epoch 改变后先核对原播放，旧时钟回调失效。文本估算用于正文对齐及原生语义调度，不向播放事件添加 PCM 进度。

semantic_status_get 按 model_id 和可选 playback_id 返回有限状态摘要，包括保存与活动映射修订、idle、active 或 suspended 状态、连接及模型代际、活动与跳过计数和暂停原因。有对应播放时，摘要附带语音连接、播放身份及代际、playback_clock、alignment_source 和当前位置。active 表示已启用的活动映射在有效连接、模型代际及关联播放上调度；suspended 携带具体暂停原因，并允许连接或模型暂未就绪。完整计划由内部调度器按播放生命周期和资源预算维护。

同一语义规则中重复出现的关键词按字符区间分别识别。同一片段的重复回调复用意图身份；被高优先控制占用而跳过的瞬时意图在该片段结束后失效。配置更新保留已经触发的命中集合，后续片段按新修订匹配。

## 配置实时生效

保存前检查批次 mapping_id 唯一、条目内 input_name 唯一，并按当前模型解析最终输出范围，拒绝同一条目不同输入指向重叠输出的配置。配置针对未加载模型保存时保留结构校验结果，在模型激活时完成能力校验。事务提交新修订后替换活动匹配快照，失败回执保留具体未激活原因。播放中的旧语义计划停止产生新写入，已持有的语义租约按其释放策略让出；以当前播放位置为下界重建剩余片段，使用 text_estimate 对齐的路径沿用当前播放时钟及估算区间，不再次触发已经播放过的关键词。

排队语音在开始播放时采用当时的活动修订。关闭语义控制立即撤销语义租约，嘴型与明确动作继续使用各自控制权。过期计划回调必须同时通过播放代际、模型代际和映射修订校验。

调度及取消见[运行时](runtime.md)，依赖方向见 [ADR 003](../adr/ADR-003-performance-arbitration.md)。
