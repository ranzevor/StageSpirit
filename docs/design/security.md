# 访问与资源边界

本文面向服务接入与资源访问实现，规定本地单用户范围内的凭据、路径、输出和业务写入边界。

首版以本地单用户配置为主要使用方式。MCP stdio 的调用权限来自启动环境和已授权连接；本地 Web 仍区分编辑、只读输出和播出应用权限。

## 本地编辑会话

Web 默认监听回环地址，接受的 Host 与端口来自当前监听配置的白名单。HTTP 与 WebSocket 在进入业务处理前校验 Host；浏览器写请求及 WebSocket 握手同时校验明确的 Origin。跨站来源和 Origin 为 null 的浏览器请求拒绝进入编辑与应用入口，CORS 凭据访问限定到已配置来源。

本机 CLI 根据当前操作系统账户权限，为选定 profile 签发有期限的一次性编辑会话引导凭据。浏览器通过同源交换建立编辑会话，一次性凭据使用后失效。Cookie 会话使用 HttpOnly、SameSite 及适用传输条件下的 Secure 标记，写请求携带与会话绑定的 CSRF 值。编辑权限与 OBS 应用权限分别校验。

明确签发给非浏览器客户端的 API 凭据使用鉴权头。此类请求按凭据范围授权，提供 Origin 时仍核对来源。WebSocket 完成会话鉴权后才能订阅或发命令，首条鉴权消息与凭据不进入普通访问日志。数据恢复后会话所属 data_generation 失效，重新建立编辑上下文。

## 凭据和输出访问

平台密钥、音频 API 密钥、OBS 密码和 VTS 令牌存放于系统凭据库，并按应用、运行配置和连接隔离。凭据库不可用时返回实际保存错误，不自动明文落盘。

配置读取和导出省略密钥值。替换、删除凭据需要明确操作；显示用掩码不能作为新密钥保存。日志过滤鉴权头、查询凭据、Cookie 和敏感正文，不记录完整音频上传内容。

展台输出使用只读、可撤销、限定候选和资源范围的令牌，绑定 profile、data_generation、output_id 及资源范围。输出凭据仅授予读取对应布局和媒体的权限，编辑与 OBS 写入由独立权限控制。访问日志脱敏 URL 中的凭据，响应采用禁止凭据页面缓存和 no-referrer 的策略。预检有效期与在播输出访问期限分别管理。

撤销输出时，服务端关闭对应订阅并拒绝后续读取和媒体请求，受控输出页面清空组件画布。候选替换遵循先准备新输出、确认生效再撤销旧输出的顺序。恢复数据后，旧代际的输出令牌和 WebSocket 订阅一并失效。

## 文件和外部连接

音频、媒体和可选模型目录使用显式授权根目录或受控资源引用。解析路径时检查规范化绝对路径、链接目标及文件类型，按目录边界校验归属。文件打开后再次核对实际句柄对应的目标，处理符号链接或重解析点在校验与读取之间变化的情况。写入使用受控目标目录及原子提交，解码和导入按同一授权范围检查。

适配器只使用目标连接的凭据，不向跳转后的其他主机转发鉴权头。用户配置的本地服务地址是该连接的显式目标，不因地址处于私网而否定其合法性；重定向、协议和远程暴露分别校验。

上传设置大小、时长和解码资源限制；压缩包导入检查路径穿越。正则、Schema 和模板只使用明确支持的本地机制，不自动访问外部引用或执行表达式。

## 正文、皮肤与媒体呈现

聊天、字幕、白板、公告和模型生成正文默认按文本节点渲染。允许富文本的字段通过结构化解析和元素、属性及 URL 协议白名单生成 DOM，移除脚本、事件属性及执行型 URL。模板按所在上下文编码占位值，业务正文不参与代码求值。

皮肤使用受控主题变量和静态资源，导入时校验资源类型与引用范围。CSP 限制脚本和网络资源来源，媒体加载继续检查资源授权；字体、图像或样式引用不能把输出凭据发送到其他来源。

## 业务写入

推流、录制、参数控制和展台应用以工具真实副作用检查目标权限。连接成功或查询成功不扩大到其他写入。已授权的日常操作按调用契约执行，不为每个工具叠加无依据的确认步骤。

面向 Agent 的消息保持业务必要字段；诊断接口与完整原始载荷另设范围。平台消息、用户正文和模型输出都作为数据处理，不能变为工具执行指令。

增加远程 MCP 或多租户前，需要新的身份、对象授权、传输和隔离设计；该能力不从本地版本自动继承。
