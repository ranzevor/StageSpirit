# ADR-003 表演控制与语义解耦

本文是面向模型和表演实现的设计记录，说明参数写入归属、独立语义配置及冲突协调的选择。

## 背景

手动动作、表情、音频嘴型和关键词动作可能控制相同模型输出。不同追踪输入可以映射到同一输出，模型重载和在播配置切换也会使旧请求失效。

## 备选方案

| 方案 | 取舍 |
| --- | --- |
| 各调用方独立写入 | 接入直接，控制权与释放竞争分散在多个入口 |
| TTS 同时负责语义及参数 | 播报路径集中，语音提供方依赖模型与表达配置 |
| avatar 统一仲裁，performance 独立配置与调度 | 在实际写入处协调冲突，语义按播放事实独立运行 |

## 设计选择

avatar 拥有全部参数写入与仲裁，performance 独立保存关键词映射、匹配正文并生成随播放调度的语义意图。手动动作、表情、嘴型及语义都进入 AvatarControl。

冲突沿实际映射识别到最终输出参数，依赖方向保持 performance 到 avatar。独立意图可以并行控制，每个意图的输出集合整组授予或跳过。同级明确参数控制保留先持有者，互斥表情组切换仍串行计算差异；语义候选在同一固定调度批次内按 priority 降序、mapping_id、model_id、intent_id 升序确定，跨批次使用当时占用并保留已跳过决定。每次授予更新 lease_id，旧授予的回调及释放失效。model_id 是运行配置内唯一的内部身份，绑定 VTS 连接及原生模型身份，配置按该身份保存，执行同时校验连接与模型代际。

## 理由与代价

写入拥有者能够覆盖全部调用入口，并按实际模型映射协调控制权。整组控制保持多参数动作的完整含义，任一输出占用时该意图跳过，可独立意图继续执行。实现需要维护模型元数据、授予身份、切换预留和外部动作观察；不能安全停止的原生动作保持占用，传输部分失败沿原操作回读恢复。

未知范围动作同时暂停相关嘴型及语义自动写入，动作结束或状态同步后按当前控制基线恢复。外部动作在被观察到后进入本地占用表。同一模型代际内的互斥组切换串行执行，部分失败回读实际状态并沿原操作恢复。新映射修订从当前播放位置重新安排未触发片段，撤销旧语义租约和回调。嘴型与明确动作各自保持控制生命周期。

播放时钟与正文对齐来源分别记录。有 PCM 但没有正文时间戳时，实际采样位置推进使用文本估算区间的计划。原生生命周期播放沿用播放器发布的单调时钟起点和时钟代际。semantic_status_get 提供当前修订、代际、调度来源、位置和暂停状态的有限摘要，详细计划另行分页或通过资源读取。

## 重新选择条件

模型或 VTS 提供新的原生混合与占用接口时，评估对应适配方式，继续保持最终参数冲突可判定、租约按所有者和代际释放。
