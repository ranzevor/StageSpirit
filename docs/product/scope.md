# 范围与独立边界

本文面向需求确认、设计和交付，定义项目身份、首版能力及扩展边界，作为需求规格的范围来源。

StageSpirit 是虚拟主播集成服务。调用方 Agent 负责回复和任务决策，服务负责连接、执行、状态、持久化及恢复。运行时的自动语义动作采用已配置的关键词规则。

## 项目身份

| 对象 | 标识 |
| --- | --- |
| 产品 | StageSpirit，中文名灵幕 |
| 仓库根目录 | StageSpirit |
| Python 分发包 | stagespirit-mcp |
| Python 导入包 | stagespirit_mcp |
| CLI | stagespirit |
| VTS 插件 | StageSpirit；认证材料按运行配置隔离 |

源码、依赖锁、安装包、文档和验收工件在新项目内闭合。运行数据位于独立应用目录，配置、令牌和 OBS 受管资源按应用及运行配置区分。导入导出使用本项目的版本化格式。

其他格式转换属于独立离线工具。复用源码和资源保留适用的权属与许可，产品运行不依赖其他项目的目录或代码包。

## 首个稳定版本

| 领域 | 必须交付的能力 |
| --- | --- |
| 平台 | Bilibili、YouTube、Twitch；聊天、SC、礼物、会员等事件；历史、过滤与关键词触发 |
| TTS | Edge、ElevenLabs、Fish Speech、Bert-VITS2、系统语音、OpenAI 兼容；音色目录、合成文件、播放队列和停止 |
| STT | OpenAI 兼容音频转写，包含 VoiceStudio |
| 形象 | 模型、道具、移动、参数、表情及组合、热键、音频嘴型 |
| 语义动作 | 独立配置、关键词匹配、持久化、实时生效、与其他动作协调 |
| OBS | 场景与场景项、可见性、文字、滤镜、推流、录制和状态 |
| 展台 | 布局、皮肤、预设、弹幕、字幕、白板、公告、模型与捕获组件；撤销重做、准备、应用和恢复 |
| 基础能力 | 全服务配置恢复、分页、操作查询、凭据管理、中文编码和独立安装 |

提供方、操作系统和目标服务的支持范围以具体适配器及版本矩阵登记。首个验收平台为 Windows；工程采用 CPython 3.12 系列，准确小版本和依赖在构建输入中锁定。

## 扩展边界

抖音、远程 MCP、多租户、集群和内置回复模型属于后续独立能力。首版的模块端口为新增渠道保留扩展位置，不为这些能力预建部署单元。

已存在的 OBS 来源通过明确绑定使用。新项目以连接、对象身份和受管记录判断可操作范围；受管展台在目标场景底部维护内部层序，其他场景项保持原有相对顺序与来源设置。普通展台应用保持当前节目场景，节目切换由独立操作表达。
