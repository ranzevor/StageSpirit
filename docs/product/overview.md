# StageSpirit 灵幕

本文面向产品使用者与接入者，说明灵幕的目标、使用场景和交互方式。具体交付范围由产品范围定义。

灵幕让声音、表情和直播画面共同参与表达。Agent 可以接收观众互动、选择音色、安排说话与动作，并将内容呈现在展台上；使用者集中管理连接、规则和播出配置。

## 使用场景

- 接收聊天、SC、礼物和会员消息，结合观众身份与完整留言参与直播互动。
- 说话时同步嘴型，根据预设关键词产生细微动作，并协调正在执行的表情和动作。
- 组合字幕、弹幕、白板、公告、模型和捕获画面，保存布局并应用到 OBS。
- 查询音色、保存服务配置、查看历史消息和操作结果，在重启后恢复设置。

## 使用方式

使用者先配置需要的服务和模型，再通过 Agent 或展台完成日常操作。语义动作单独配置一次，普通语音调用即可自动使用。发声标签交给语音服务，字幕展示清理后的正文。

每个直播平台和音频提供方都通过自己的连接管理。新增渠道沿用相同的查询、配置和使用方式，让使用者可以根据角色、语言和声音效果选择服务。

## 产品取向

本地优先，配置长期保存，业务信息完整，控制结果清楚。常用操作保持直接，复杂操作提供可查看的准备结果和恢复入口。工程范围见[范围与边界](scope.md)，工具调用见[Agent 使用指南](../guides/agent.md)。
